
Este projeto apresenta um exercício básico de algoritmos e programação em Java, utilizando vetores para armazenar números inteiros.

O programa solicita ao usuário 5 números inteiros e organiza os valores em ordem crescente, utilizando estruturas de repetição e comparação entre os elementos do vetor.

## Tecnologias utilizadas

Java  
Scanner para entrada de dados pelo teclado.  
Vetores para armazenar os números.  
Estruturas de repetição `for` para percorrer e comparar os valores.  
Estrutura condicional `if` para comparar os elementos e realizar as trocas de posição.

## Funcionamento

1. Solicita ao usuário a digitação de 5 números inteiros.
2. Armazena os valores em um vetor.
3. Compara os elementos do vetor utilizando estruturas de repetição.
4. Troca os valores de posição quando necessário.
5. Organiza os números em ordem crescente.

## Objetivo

Praticar conceitos fundamentais de programação em Java, incluindo declaração de variáveis, entrada de dados, vetores, estruturas de repetição, estruturas condicionais e ordenação de números inteiros.

## Finalidade

Exercício desenvolvido para fins acadêmicos na disciplina de Algoritmos de Programação
